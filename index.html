Captions are generated by Xenova/vit-gpt2-image-captioning running locally through Transformers.js. It uses your GPU when one is available and falls back to the CPU. The first run downloads the model once, then the browser caches it — serve this page over http://localhost so that cache can be used.

Always read the captions before you ship them. A machine can describe an image; only you know what it is for.
